# AI 学习工作台

静态 HTML/CSS/JavaScript，部署于 GitHub Pages；PWA 联网优先，离线回退缓存。

## 免费更新

GitHub Actions 每日北京时间 05:55、17:55 抓取 RSS，可能受队列延迟影响。更新脚本已移除付费模型调用，不读取模型 API 密钥。国内媒体之外，增加 OpenAI 官方 RSS 与 Hugging Face 平台博客；英文来源保留原文，不用规则替换冒充准确翻译。官方博客也需要判断相关性，来源身份不等于报道已人工核实。

安装 `feedparser`，在项目目录运行：

```shell
python scripts/check_news_rules.py
python scripts/update_news.py
python scripts/update_content.py
python scripts/update_content.py --dry-run
```

`--no-ai` 保留兼容，有无该参数都只走免费规则。`check_news_rules.py` 使用站内真实历史标题检查分类、传闻排除与版本去重，并不核实报道事实，也不代表真实新闻集的统计准确率。

## 新闻分类

栏目保持国内/国外动态、新模型速报、行业大事记、论文快报。国内/国外按标题中的厂商/产品判断，混合合作报道可能归国内，规则不能完全解析句子主体。

每条标签为：模型发布、价格与额度、工具与智能体、评测与研究、行业动态、其他。明确论文/报告优先；然后价格与额度、普通评测、工具、模型发布、行业事件。明确的泄露/爆料/传闻/疑似报道不加入新增动态。专项归档按学术、模型发布、行业的顺序互斥；普通跑分属于评测，但不进入论文快报。历史栏目不搬动，只重标标签。

## 更新状态与人工证据

`data/site-status.json` 记录两条更新链路的最后尝试、最后成功、最后新增、来源结果以及成功无变化/部分失败/全部失败。失败不会覆盖上次成功时间；无新增不会伪造新增时间。页面展开“更新状态”可查看，离线可能显示缓存记录。

`data/core-sources.json` 是价格、规格、套餐和应用热度的逐条来源台账。迁移记录默认待核对，未知 `evidence_published_at`、`reviewed_at` 留空；原页面核对日期仅是继承注记。确认某条数据时，人工更新值、直接证据 URL、原文发布日期和实际核对日期，再同步页面表格。产品官网入口不等于热度或价格的直接出处。自动新闻与每周核对不会改核心数据、评分或人工核对日期。

## 保留与归档

每个动态栏目最多展示最近 90 天、60 个日期块。超出范围的完整区块先写入 `data/news-archive.jsonl`，再从页面移除；新闻页提供标题搜索。归档保留原块，不改变旧报道。归档文件不提前加载，长期仍可能增长，可按年度进一步拆分。

已见 URL 保存处理时间，保留 90 天、最多 2000 条；旧列表首次迁移会标为 legacy，迁移时间不冒充原文发布日期。工作流会提交状态、归档与已见记录。

维护时以最新 main 为基线，勿用旧本地 HTML 覆盖机器人更新；只上传本次修改的文件。不要在代码、文档或仓库 Secret 中存放个人付费模型密钥。浏览器中其他服务商的个人聊天配置独立于免费新闻链路，手动调用仍可能收费。
