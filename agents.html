🌏 国内外差异

不是谁强谁弱，是路线不同

🌍 国外路线

  • 模型上限更高：GPT / Gemini / Claude 原生 agentic 能力领先
  • 开源 Agent 繁荣：OpenClaw / Hermes 可完全自托管
  • 全球化生态：Slack / Discord / VS Code 插件最全
  • 短板：国内访问受限、需科学上网、高峰期排队、企业数据出境合规

🇨🇳 国内路线

  • 生态深度融合：微信 / 抖音 / 飞书 / 钉钉原生打通
  • 免费为主：C 端几乎不收费，合规与私有化完善（Dify / AutoClaw）
  • 系统级入口：手机厂商预装，覆盖人数最多的入口
  • 办公 Agent 爆发：WorkBuddy / 百度搭子 / 千问办公三强混战
  • 短板：顶尖模型上限略逊、国际渠道与多语言弱

🧩 想自己搭一个，选哪条路

4 条主路径

「用别人的 Agent」和「自己搭 Agent」是两件事。如果你的需求是企业内网、数据不能出本机、流程要可控，就得走自建。四条主路径的取舍如下。

路径门槛部署最适合代价
扣子 Coze零代码云托管5 分钟搭 Bot 并分发到飞书 / 抖音数据在云上，复杂流程编排受限
Dify会配置可私有化企业知识库问答、可控 LLMOps需要运维，C 端体验不是目标
智谱 AutoClaw装个客户端本地一键本机文件 / 浏览器自动化，数据留本地偏个人，团队协作能力弱
OpenClaw会折腾完全自托管接入 IM、自定义工具、模型自由路由无官方 SLA，安全需自己加固
